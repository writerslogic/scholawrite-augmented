# Extended Analysis Suite

This suite contains eleven analysis scripts organized into two categories. The first category (01-05) provides **empirical validations**: cross-dataset classification, synthesizer benchmarking, clinical-grade signal validation via Parkinson's disease, emotion-state modulation, and writing-quality correlation. Together these establish that the process signals capture genuine cognitive phenomena across independent datasets and tasks. The second category (06-11) provides **theoretical contributions**: authorship fingerprinting via signal distance matrices, adversarial channel capacity bounds, simulation calibration against ground-truth human data, an entropy floor test, Shannon channel-capacity analysis connecting empirical AUC to information-theoretic upper bounds, and within-document cognitive-regime detection. These analyses collectively support the paper's core claim that keystroke process signals provide attestation that is both empirically robust and theoretically grounded.
